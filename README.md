## Hi, I'm Abhishek 👋

Backend engineer at **Thinsil Technologies**, building **Techbench**, a live B2B contract-staffing SaaS: five microservices on **Python, Django REST Framework, PostgreSQL, Redis, Celery, Kafka and Docker**, behind Nginx and deployed through GitHub Actions.

### What I work on

- **Billing correctness**: timesheets to monthly client and vendor invoices. I fix the bugs where money goes wrong: double-billed days, lost days, and a quoted total that differs from the billed one.
- **Upload security**: one validator for every upload path that checks files by their bytes, not their names. It catches malicious PDFs, macro documents, polyglots and zip bombs before they reach S3.
- **Reliability**: zero-downtime rolling deploys gated on health checks, encrypted off-host Postgres backups with monthly restore drills, and a watchdog that alerts before users notice.
- **Performance**: hunting N+1 queries and adding guards so they can't come back; Postgres connection pooling.
